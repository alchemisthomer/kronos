# 07_aborted/

Engagements that stopped before shipping live here. Possible reasons: first-signal-stop triggered and the engagement chose to close rather than continue with a scoped finding; ROE violation detected mid-execution; authorization artifact expired before the attack matrix completed; approver revoked authorization; framework crash.

**Entry:** any abnormal termination → `git mv` from `../04_running/` or `../05_evidence/`.

**Exit:** none. Aborted engagements are permanent record.

The engagement document's §13 closeout must be filled with the abort rationale. Aborted engagements do NOT update the scorecard — an aborted engagement is not evidence about the target's defensive posture, only about the engagement's own inability to complete.
